🧠 Interactive Quiz Application

An interactive, multi-category quiz web application designed to test general knowledge, technical concepts, and development skills. The application provides a smooth and engaging quiz experience with a modern interface, real-time score tracking, instant answer feedback, and animated progress indicators.

✨ Features

Multiple Quiz Categories: Explore different categories and test your knowledge across various subjects.

Interactive Quiz Interface: Smooth multi-screen navigation for an engaging experience.

Real-Time Score Tracking: Automatically updates your score as you answer questions.

Instant Answer Feedback: Get immediate visual feedback for correct and incorrect answers.

Animated Progress Bar: Track your progress throughout the quiz.

Responsive Design: Optimized for desktop, tablet, and mobile devices.

Dynamic Question Flow: Move between questions with an interactive quiz experience.

Results Summary: View your final score after completing the quiz.
